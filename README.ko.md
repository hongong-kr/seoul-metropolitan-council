# seoul-metropolitan-council

지방의회 행정사무감사 생중계를 모니터링하는 재사용 스킬. 그룹 채널에 실시간 알림을 보내고, 회의록을 두 단계(잠정본 → 정정본)로 작성한다.

## 포함 내용

- **회기 전 준비** — 브리핑 자료, 위원회 명단, 일정 확인.
- **실시간 모니터링** — 약 5분 간격 확인. 개시·정회·재개·종료와 관련 포착 사항 알림.
- **자막 상태 대응** — 자막이 정상·없음·멈춤·복구될 때의 여섯 가지 경우별 판단 기준.
- **공백 기록** — 확인하지 못한 구간을 임의로 메우지 않고 기록하는 방법.
- **문서 작성** — 영상회의록(VOD) 기반 잠정본, 공식 문자 회의록 대조 후 정정본. 수감기관 본인의 청문일에는 실시간 표를 유지한다.
- **메시지 틀** — 개설 안내, 당일 감시계획, 청문일 안내, 실시간 갱신 알림, 문서 안내, 하루 마감, 종료·의견 요청 안내.
- **도구 참고자료** — 녹화(yt-dlp, streamlink), 전사(WhisperX, WhisperLiveKit), 간격 자막 확인(jiffshot) 등 매뉴얼의 빈틈을 메우는 오픈소스 도구.

## 사용법

`SKILL.ko.md`를 AI 에이전트의 스킬 디렉터리에 복사하고 자리표시자를 바꾼다.

- `[대상 기관]`, `[운영자 직위]`, `[운영자 성명]`
- `[감시 기간]`, `[청문일]`, `[종료 설문 URL]`
- "회기 전 준비"에 있는 참조 URL(예시는 서울특별시의회)

스킬은 범용으로 썼다. 실명, 내부 채널, 고정된 날짜는 들어 있지 않다.

## 출처

2026년 의회 감사 모니터링 운영(11월 6~13일)에 쓴 업무 매뉴얼의 절차를 일반화한 것이다. 내부 세부사항은 뺐다. 전사와 실시간 모니터링 참고자료는 깃허브에서 찾았다.
